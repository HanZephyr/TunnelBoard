# Linux 正式支持范围与系统级本地 CA 信任

Linux 正式支持 Debian 12+、Ubuntu 24.04 LTS+ 与 RHEL 兼容系 9+ 的图形桌面会话，并分别以 `.deb` 与 `.rpm` 原生包交付 `amd64` 和 `arm64`，不支持 32 位 ARM、已停止维护的 CentOS Linux、无头服务器或首发 AppImage，也不增加脱离用户会话运行的 systemd 系统服务。正式 UI 验收覆盖 GNOME 与 KDE Plasma 的 Wayland 会话；X11 仅做基础启动和退出 smoke，不承诺完整托盘体验。发布资产经 TunnelBoard 专用 GPG 密钥签名并附带 manifest 与 `SHA256SUMS`：主密钥离线保存，GitHub Actions 只使用受限签名子密钥，发布页固定公布公钥与指纹。首发只通过 GitHub Release 手动分发和升级，不建立 APT/DNF 软件源或应用内自更新。所有四个 Linux 原生包必须先通过自动化构建和完整性校验，再在 GNOME/KDE Wayland 真机或图形 VM 完成权限、CA、浏览器、托盘、自启、升级与卸载验收；缺少真机证据的候选只能保持 draft。为使内置 Caddy 签发的本地 HTTPS 证书能被主流系统客户端可靠验证，TunnelBoard 在用户确认完整 CA 指纹并完成系统授权后，将唯一的本地 CA 写入系统级信任库；不自动修改 Firefox、Chromium 或其他应用的用户 Profile。该选择会影响同机其他用户的信任边界，因此最后一个启用 Caddy 的 Web Route 移除时必须精确撤销该 CA。无证书告警的正式验收只覆盖原生安装的 Firefox 与 Chromium；Snap、Flatpak 等沙箱浏览器仅尽力兼容。普通卸载停止 TunnelBoard 并删除其受托管 hosts 区块和唯一系统级本地 CA，但默认保留当前用户的 Vault、密钥、备份和日志。
