# Linux 使用受限 polkit 特权适配器

Linux 的系统级 hosts 与本地 CA 操作由安装包内的非持久化特权程序执行，并以 `io.github.hanzephyr.TunnelBoard.manage-system` 专属 polkit action 请求系统授权。该程序只接受受托管 hosts 更新、安装或撤销唯一 TunnelBoard 本地 CA、刷新系统信任库等高层操作；不安装 systemd 服务、不复用 Windows 会话 Helper、也不执行 UI 或调用方传入的任意 root 命令。主程序先以自身的 PID、启动时间和 UID 通过 polkit Authority 申请可交互的临时授权，必须取得 opaque authorization ID 后才以 `pkexec --disable-internal-agent` 启动包内 helper；helper 对实际父进程、PID 启动时间、固定已安装程序路径和 `PKEXEC_UID` 做校验，并在每次副作用前枚举临时授权，核对 ID、action、进程 subject 与未过期时间。临时授权和 root 会话都以五分钟为上限；正常退出、IPC 断开或到期时先停止 root 会话，再按该 authorization ID 精确撤销，绝不调用会影响其他应用的批量撤销接口。异常退出由父进程死亡信号与 subject 绑定阻止新进程复用，临时授权的系统 TTL 作为额外兜底。这样保留 Linux 桌面原生授权体验，同时把系统级权限面限制在产品已确认的副作用内。
